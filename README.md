# WebAI — The AI-generated Web Reference Portal

WebAI is an **independent, bilingual (FR/EN) reference portal** about the Web generated by and for artificial intelligence. Inspired by the reference taxonomy of Augmentiverse.org (concept, technologies, standards, tools, applications, people, chronology, glossary and bibliography) but with an original scope and independently authored source-linked content.

**Primary navigation:** Concept · Technologies · Standards · AI Tools · Applications · Research · Ecosystem · Observatory. A secondary, visible navigation offers encyclopedia, bibliography, glossary, timeline, FAQ, WebAI Lab and research utilities.

## Reference edition — 13 November 2026 (PR #4)

- **36 encyclopedia dossiers**, each with six substantive bilingual sections, source references, practical methods, limits and critical questions.
- **51 documented tools**, each with a detailed bilingual profile and **three additional supporting references** beyond its official website; **102 localized tool detail pages**.

### Run

```bash
npm install
npm run dev
npm run build
npm run preview
```

Node 22+. Astro output is static in `dist/`. For this reference redesign preview use branch `feat/research-atlas-expansion-2026`; leave `main` unchanged until reviewed. All preview routes have `noindex,nofollow`.

### Editorial model

- Source URLs are primarily original specifications, providers, or papers.
- Pricing and maturity are not asserted without a dated review.
- Sources and educational drafts are separate data types.
- No Phase III `a_verifier` content is published as validated.
- No external scripts, analytics, model APIs, secrets or payments are required.
- WebAI is independent of the W3C Web & AI Interest Group.

See `docs/EDITORIAL_POLICY.md` and `docs/ROADMAP.md` for the review pipeline.

## English-language experience

- The English edition starts at `/en/`; the French edition stays at `/fr/`.
- A permanent `FR | EN` selector in the header and native-name links in the footer preserve the current route, including its search query.
- Both language editions have their own titles, descriptions, navigation, encyclopaedia dossiers, curated resources, search and interactive workshops.
- Each built page declares its HTML language and FR/EN alternate URLs, so crawlers and assistive technologies can identify the correct language. Preview pages remain `noindex,nofollow`.
- `npm run verify:locales` checks equivalent routes, visible language controls and alternate metadata for each page; it does not replace editorial translation review.
